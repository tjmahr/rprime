# Convert a list of `EprimeFrame` objects into a `FrameList` object

Convert a list of `EprimeFrame` objects into a `FrameList` object

## Usage

``` r
as.FrameList(xs)
```

## Arguments

- xs:

  a list of
  [`EprimeFrame()`](https://www.tjmahr.com/rprime/reference/EprimeFrame.md)
  objects

## Value

the original list as a
[`FrameList()`](https://www.tjmahr.com/rprime/reference/FrameList.md)
object
