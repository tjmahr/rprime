# Package index

## Most important functions

- [`read_eprime()`](https://www.tjmahr.com/rprime/reference/read_eprime.md)
  : Read in a text file generated by Eprime

- [`example_eprime_file()`](https://www.tjmahr.com/rprime/reference/example_eprime_file.md)
  : Locate a bundled example Eprime file

- [`FrameList()`](https://www.tjmahr.com/rprime/reference/FrameList.md)
  :

  Convert lines from an Eprime file into `EprimeFrame` objects

- [`filter_in()`](https://www.tjmahr.com/rprime/reference/filter_in.md)
  [`filter_out()`](https://www.tjmahr.com/rprime/reference/filter_in.md)
  :

  Filter levels in or out of a `FrameList` based on attribute values

- [`keep_levels()`](https://www.tjmahr.com/rprime/reference/keep_levels.md)
  [`drop_levels()`](https://www.tjmahr.com/rprime/reference/keep_levels.md)
  :

  Filter levels in or out of a `FrameList` based on `Eprime.Level`
  values

- [`to_data_frame()`](https://www.tjmahr.com/rprime/reference/to_data_frame.md)
  :

  Convert `EprimeFrame` objects into dataframes

## Supporting functions

These help with the parsing of the text file.

- [`listify()`](https://www.tjmahr.com/rprime/reference/listify.md) :
  Convert a vector of colon-separated text lines into a list of named
  elements
- [`extract_chunks()`](https://www.tjmahr.com/rprime/reference/extract_chunks.md)
  : Extract log-frames from an Eprime log file
- [`preview_eprime()`](https://www.tjmahr.com/rprime/reference/preview_eprime.md)
  [`preview_levels()`](https://www.tjmahr.com/rprime/reference/preview_eprime.md)
  [`preview_frames()`](https://www.tjmahr.com/rprime/reference/preview_eprime.md)
  : Preview the levels in a parsed Eprime file

## Objects

These objects represent chunks of data.

- [`EprimeFrame()`](https://www.tjmahr.com/rprime/reference/EprimeFrame.md)
  :

  Create an `EprimeFrame` object

- [`as.EprimeFrame()`](https://www.tjmahr.com/rprime/reference/as.EprimeFrame.md)
  :

  Convert a list into an `EprimeFrame` object

- [`as.FrameList()`](https://www.tjmahr.com/rprime/reference/as.FrameList.md)
  :

  Convert a list of `EprimeFrame` objects into a `FrameList` object
