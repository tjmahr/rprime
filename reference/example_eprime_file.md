# Locate a bundled example Eprime file

Locate a bundled example Eprime file

## Usage

``` r
example_eprime_file(which)
```

## Arguments

- which:

  A short name or full filename identifying an example file. Omit
  `which` to print the available names and filenames.

## Value

A filepath to the selected file. If `which` is missing, the named vector
of available filenames is printed and returned invisibly.

## Details

This function uses
[`system.file()`](https://rdrr.io/r/base/system.file.html) to locate
files bundled with rprime. Available short names are `Blending`, `MINP`,
`MP`, `SAILS1`, `SAILS2`, and `not_an_eprime_file`.

`MP` contains an interrupted experiment. `not_an_eprime_file` is a
non-Eprime file used to demonstrate how
[`read_eprime()`](https://www.tjmahr.com/rprime/reference/read_eprime.md)
handles such input.
