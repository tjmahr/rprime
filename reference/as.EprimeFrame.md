# Convert a list into an `EprimeFrame` object

Convert a list into an `EprimeFrame` object

## Usage

``` r
as.EprimeFrame(xs)
```

## Arguments

- xs:

  a list

## Value

the original list as an
[`EprimeFrame()`](https://www.tjmahr.com/rprime/reference/EprimeFrame.md)
object (along with dummy Eprime metadata fields)
